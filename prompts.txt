================================================================================
HOW TO RUN
================================================================================

The scraper file is ONLY `project/scraper.py`. There is no `scraper.py` at the repository
root by design—always run one of the following.

A) Recommended (from inside `project/`):

cd project
python scraper.py

B) From the parent folder (e.g. `ekantipur_data_extraction` one level above `project/`):

python project/scraper.py

(Using `python scraper.py` from the parent folder will fail because Python looks for a
file named `scraper.py` in the current directory, which does not exist there.)

What you should see:
- A Chromium window opens (headless=False).
- Console logs prefixed with [nav], [task1], [task2], [io], [browser].
- `output.json` is overwritten at the end of the run (even if scraping partially fails).

================================================================================
SELECTORS USED (AND WHY THEY ARE STABLE)
================================================================================

Entertainment listing (Task 1)
- `div.category-main-wrapper div.category-wrapper > div.category`
  - Each entertainment row is a `.category` block with a text column (`.category-description`)
    and an image column (`.category-image`). This maps to the visible homepage/listing UX
    and avoids ultra-deep `div > div > …` positional selectors.

Title + URL
- `.category-description h2 a`
  - The headline is consistently an `h2` link on the 2026 template.

Author (optional)
- `div.author-name`
  - When present, it contains the byline (sometimes multiple links). If missing/empty → JSON `null`.

Images
- `.category-image img` with `src` / `data-src` / `data-original`
  - Thumbnails are often absolute `thumb.php` URLs; we still normalize relative URLs when needed.

Cartoon widget (Task 2)
- `section.e-section` that contains `div.cartoon-slider`
  - The live homepage labels the module “कार्टुन” and uses Swiper (`.swiper-slide-active`).
- Fallback: visible text containing “व्यंग्यचित्र” + nearest ancestor that contains an `<img>`
  - This keeps the script useful if the homepage module is renamed again.

================================================================================
COMMON DEBUGGING TIPS (PLAYWRIGHT + NEWS SITES)
================================================================================

1) `networkidle` timeouts
   - News sites load ads, trackers, and streaming beacons for a long time.
   - This project aborts a small set of known tracking hosts so Chromium can reach
     `networkidle` more reliably without changing the editorial markup.
   - If you still time out, temporarily add `page.pause()` for interactive debugging (remove
     for automation).

2) Use Playwright Inspector
   - `PWDEBUG=1 python scraper.py` (environment dependent) opens stepping tools so you
     can see which locator resolves to which element.

3) Prefer role-based locators for navigation
   - `get_by_role("link", name=...)` tracks accessible names, which often survive CSS churn.

4) Bot / 403 issues with raw HTTP clients
   - Plain `urllib` calls may get blocked while real Chromium succeeds; this is why the
     scraper sets a conventional desktop User-Agent.

5) Nepali text “looks wrong” in some editors
   - Always open `output.json` as UTF-8. The script writes UTF-8 explicitly.
